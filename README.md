# BeatShape


Zum Starten des Projekts wird Node.js benötigt. Danach können die Projektabhängigkeiten über npm installiert werden.

## Installation

Abhängigkeiten installieren:

```bash
npm install
```

## Anwendung lokal starten
```bash
npm run dev
```

Danach ist die Anwendung im Browser unter der Adresse erreichbar, die im Terminal angezeigt wird. Standardmäßig ist das meistens:

```text
http://localhost:5173/
```
